# Apex Hackathon AI 🚀

An autonomous, multi-agent graph engineering system built with **LangGraph** and **Python**. It is designed to research, architect, and ruthlessly evaluate hackathon ideas to produce winning technical specifications and pitch decks.

## Architecture & Features
- **Adversarial Researcher:** Scrapes competitor weaknesses and identifies true innovation gaps.
- **Shoestring Architect:** Enforces a $0-budget constraint, using open-source tools and free-tier infrastructure.
- **Red Team Judge:** Adversarial feedback loop that grades designs on Novelty, Feasibility, and Scale.
- **Deliverables Master:** Generates 6-slide SIH-formatted pitch decks and repository structures.
